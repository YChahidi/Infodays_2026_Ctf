Phishing Pipeline — n8n Flow

Flow diagram

  1. Webhook receives a POST with {campaign_id, email, message}.
  2. Signature is computed as HMAC-SHA256(secret, JSON.stringify(body)) and compared to the x-gophish-signature: sha256=… header.
  3. On match, the pipeline looks up the email in phishing.victims.
  4. If that query errors out, the "DEBUG: REMOVE SOON" node echoes the failure back to the caller. (still need to remove this in prod!)

Example request

POST /webhook/{{ webhook_id }} HTTP/1.1
Host: localhost
Content-Type: application/json
x-gophish-signature: sha256=<hex>

{"campaign_id":1,"email":"striker1@club.lab","message":"Clicked Link"}
